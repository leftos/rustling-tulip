Status window: three options

"A semi-translucent, opaque on hover, status window, that can stay tucked in a corner of the monitor, and shows a smart status of running sessions, what agent needs me if any, short progress updates, etc."

Each frame is the bottom-right 600×560 of a 1920×1080 desktop at 1:1, so the window is drawn at its real size, 12px above the taskbar. Left frame: idle at 55% opacity (hover it: the CSS hover is real). Right frame: hovered, forced opaque. Every lane shows the same 7 sessions.

WorkingAwaiting input (needs you) IdleEnded Minimap: filled = idle footprint, dashed = hovered footprint
Opacity is whole-window alpha, the way a layered window renders it: text fades with the background, and no acrylic blur is assumed. Fake data; desktop background drawn on a canvas.
