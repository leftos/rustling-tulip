Gate log, tailed in the app

Clicking a gate row (a running slot, a queued run or a recent run) opens its log inside rustling-tulip instead of the OS default app. The view follows the log as the gate writes it, kept scrolled to the end like tail -f, and shows the last 2,000 lines, so a build log over the viewer's 2 MiB limit still opens. Scrolling up pauses following; "Follow" resumes it.

AA log tab beside the session tabs

The log opens as a tab named after the command, like a file viewer tab. Clicking the same gate again focuses its tab. The header shows the slot, the gate's live state and elapsed time, with Follow, Copy path and Open in default app. When the gate ends, the chip turns to Passed or Failed and the tab stays open.

BA log pane inside the active tab, split under the gates' work

The log opens in a pane split into whatever tab is showing, like a terminal pane, so you can watch it beside a session. It closes with the pane's ×. For a recent run that failed, a banner gives the result and the log opens at its end, where the failure is.
