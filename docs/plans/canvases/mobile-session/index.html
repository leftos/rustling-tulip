C. The dock follows the prompt

While a hook reports a pending prompt, the dock shows its options as big buttons; a tap types the option's number (never its label). ↑ ↓ Esc stay under them for anything else. With no prompt pending, the dock falls back to A (Quick and Keys behind buttons).

Worst case: a menu no hook reports (a TUI inside a plain shell, a prompt from a tool Claude runs) gets no buttons and falls back to the keys; if the hook's options and the drawn menu ever disagree, a tap sends the wrong number.
