Performance monitor

The same sample data in three placements. Every pane is a group whose row adds up its whole process tree, from the tracer and shell down to the agent and anything it spawned, such as cargo, rustc and MCP servers. "rustling-tulip" holds the app's own processes (client, daemon). "Other processes" is the rest of the machine, so the column totals match the OS-wide meters. CPU % is of the whole machine, as in Task Manager. Memory is each process's private working set.

AA rail view beside the panes, like Gates

Opened from the rail. It stays open while you work, so a busy build is easy to watch. The tree is narrow, with Name, CPU and Memory only; PID and the full command line show on hover.
