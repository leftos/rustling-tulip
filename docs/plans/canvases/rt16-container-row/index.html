3 · How a container row gains keyboard focus

All three fold with Enter or Space once the row is focused. The open part is how focus arrives. The ring is the app's existing 2 px ACCENT focus ring.

A · Click to focusA

Worst case: with no pointer in play there is no way to move keyboard focus onto a row, so the fold keys stay mouse-first.

▾⑂acme-apirepo2
▸▦Acme Workspacews3

A click on a row focuses it; Enter/Space folds that row. No Up/Down or Tab traversal — Tab keeps going to the terminal.

B · Up/Down in the sidebarB

Worst case: the arrows stop reaching the focused terminal whenever the sidebar holds focus, so the user must click the terminal to type an arrow again.

▾▦Acme Workspacews3
▾⑂acme-apirepo2

A click focuses the row; Up/Down move the focus container by container; Enter/Space folds; Escape returns focus to the terminal.

C · Tab through rowsC

Worst case: Tab stops being a way back into the terminal from the sidebar, and a long container list makes reaching the last row many presses.

▾▦Acme Workspacews3
▾⑂acme-apirepo2

Tab moves row by row (Tauri's tabIndex behaviour); after the last row, Tab returns to the terminal.

4 · Detached banner wording

The Tauri text ends “Use the session header to stop or pop them out”, but native has no pop-outs until Phase 5 and stop-all is P4.11b; the banner must not promise a control that does not exist.

A · Adapted Tauri textA

Worst case: three lines of grey text above the very sessions the user is looking for.

These sessions are still alive, but their repo or workspace is no longer registered. Stop them from each session’s header.

B · ShortB

Worst case: it says what happened but not where the controls are.

These sessions are still running. Their repo or workspace is no longer registered.

C · Short with where to actC

Worst case: it is the longest of the two short options, and the Resume hint duplicates the button once C in section 1 is chosen.

These sessions are still running, but their repo or workspace is no longer registered. Resume one from its row, or stop it from its header.

Already ruled, not asked: fold keys are Enter/Space; ▶ launch-last and double-click are RT-19 (P4.11b); Detached “stop all” is RT-19; the count of abandoned sessions is every is_abandoned snapshot (the same set the daemon’s bulk resume acts on); an empty container row stays focusable; Escape clears the row focus before it drops an armed confirm; Resume all has no pending state (failures toast one per session); the parity line for the container row stays unticked until RT-19 lands.
