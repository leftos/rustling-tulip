# Petal: the native client's new look

The user approved "Petal" for the native client (`apps/native`): a graphite ground, a tulip-coral accent, Schibsted Grotesk as the UI face beside Geist Mono, status shapes as well as colours, and refined pane headers and chips. The canvas is https://claude.ai/artifact/B5hxrVTyyR635CQecEpG2N (seven boards), saved in the repo as [canvases/petal/](./canvases/petal/): one `.dc.html` per board (`Main`, `Spawn`, `SourceControl`, `SettingsAlerts`, `Dashboard`, `Conversation`, `PhoneDashboard`) and `canvas.json`; re-save it when the canvas is republished. Index line: [MAIN.md](./MAIN.md), the Petal wave. This subplan splits the look into brief-sized items that build on today's code, records what is settled, and keeps the questions the boards left open with the user's answers.

## Rulings

- **Order (user):** Petal lands before the rest of native Phase 4, so it is MAIN.md's Wave 1, ahead of Waves 2–5. P4.12b / P4.12c (Wave 2, in `spawn_form.rs` / `session_menu.rs`) wait for it; PT.8a and PT.8b restyle the menu and dialog they extend. Waves 2–5 then build their new UI with Petal's tokens directly.
- **Scope:** only what exists today is restyled, plus two small board details whose data exists (the footer's status counts and the Session button's `Ctrl N` hint, Q9) and the leaf-density setting (Q6). The boards' unbuilt features are visual targets for their own waves, not items here:
  - Dashboard board, the tab bar's Terminals / Dashboard switch and its badge, the rail's Needs You view, the asking toast that quotes the command → Wave 7 (Alerts, Dashboard and Needs You), on Wave 6's `pending_input`.
  - Settings → Alerts board → Wave 7 (spoken alerts, SA steps).
  - Conversation board and the pane header's Terminal / Conversation toggle → the backlog idea "Conversation view (GUI mode)", which has no wave yet.
  - Phone dashboard board → Wave 12 (mobile app, MA6 monitor and respond).
  - Subagent rows under a leaf → Wave 8; the `DS` dispatch leaf → Wave 9; the PR / issue chips (`#412`, `#1187 draft`) → the backlog idea "Link a worktree to a GitHub issue or PR".
- **One palette module.** Every UI colour lives in a plain-Rust `apps/native/src/palette.rs`; views name tokens, never literals. `lib.rs` re-exports the names its 27 importing files use today (`TEXT`, `MUTED`, `BORDER`, `PANEL_BG`, `BAR_BG`, `HOVER_BG`, `DANGER`, `WARNING`, …), so recolouring is a change to one file. ## Open questions

Answered (user): Q1 (a) four static Schibsted Grotesk TTFs; Q2 (a) Geist Mono stays at 400 and 700; Q3 (a) per-session accents kept, with Petal's presets; Q4 (a) unseen turns, a client-side set cleared on focus, shells always the dot; Q5 (a) the board's sizes plus the extra glyphs for spawning, stopped and error; Q6 (c) a Compact / Comfortable leaf-density setting (Comfortable the default, in Settings → General); Q7 (a) ground #0C0B0E, ANSI as is, Graphite renamed Slate; Q8 (a) 8 px rounded frames; Q9 (a) the footer counts and the `Ctrl N` hint in PT.5 / PT.6a; and the build-time details (footer separators and status text, the REPO icon, Commit's colour, string colour, the gutter, the accent line, the member chips) in the PT.5 / PT.6a / PT.7 / PT.9 details. All are folded into the Rulings and the items above.

1. **Schibsted Grotesk: licence and bundling.** It is SIL OFL 1.1 with no Reserved Font Name (upstream `github.com/schibsted/schibsted-grotesk`, release 1.100, also in `google/fonts` `ofl/schibstedgrotesk`), so bundling beside the four OFL mono families is allowed with its `OFL.txt`. The boards use weights 400–700 (800 only for the `!` badge).
   - (a) Recommended: four static TTFs from the repo's `fonts/ttf/` (Regular, Medium, SemiBold, Bold; 490,976 bytes together), the `!` badge drawn at Bold. Worst case: the exe grows by about 0.5 MB, and a future italic needs another file.
   - (b) The variable TTF, one file. Worst case: whether GPUI 0.2.2 on DirectWrite picks weights from a variable font's axes is unmeasured; every weight might render as the default instance.
   - (c) No bundle; the root asks for "Schibsted Grotesk" and falls back to Segoe UI Variable. Worst case: nobody without the font installed sees Petal's type.
2. **Geist Mono's middle weights.** The boards' mono chips use 500 and 600; only 400 and 700 are bundled.
   - (a) Recommended: draw chips at 400 and bold headers at 700. Worst case: chips read a shade lighter than the board.
   - (b) Add Geist Mono Medium and SemiBold (about 300 KB). Worst case: two more faces the terminal font list never uses.
