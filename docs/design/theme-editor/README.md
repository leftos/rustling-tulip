# Theme selector and editor: layout mock (RT-583)

`index.html` draws three selector layouts (S1 cards in Settings → Appearance, S2 a Themes modal, S3 a footer quick switcher) and three editor layouts (E1 grouped tokens beside a live mini-preview, E2 edit in place with a docked inspector, E3 UI tokens beside the terminal palette), in the Contrast look, with each theme's preview drawn from its own values. The theme values in it are placeholders, not the shipped themes.

**Chosen by the owner:** S2, the Themes modal, and E1 with E2's pick mode. Recorded on RT-583 in Linear.
